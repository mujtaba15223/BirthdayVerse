# BirthdayVerse

### An Interactive Digital Birthday Experience

BirthdayVerse is a personalized interactive birthday website built from scratch using HTML, CSS, and JavaScript.

It transforms a simple birthday message into an interactive journey with personalization, animations, transitions, a gift reveal, and a final celebration.

---

## ✨ Features

* 🎂 Personalized birthday experience
* ✍️ Dynamic name input
* 🌌 Animated stars and clouds
* 📖 Multi-step interactive journey
* 🎁 Interactive **Open Gift** experience
* 🎉 Final surprise section
* 🍰 Birthday cake animation
* 🎊 Confetti celebration effect
* ✨ Interactive transitions
* 📱 Responsive web experience
* ⚡ JavaScript-powered interactions
* 🌐 Deployed with Vercel

---

## 🎨 How It Works

BirthdayVerse is designed as an interactive journey rather than a traditional static birthday webpage.

### 1. Enter a Name

The user enters the name of the person whose birthday is being celebrated.

The name is then dynamically displayed throughout the experience.

### 2. Explore the Journey

The user progresses through multiple interactive stages with animated backgrounds, transitions, and personalized content.

### 3. Open the Gift

An interactive **Open Gift** experience leads into the main surprise.

### 4. Final Celebration

The experience ends with a personalized birthday celebration featuring:

* Birthday cake animation
* Confetti
* Personalized content
* Celebration effects
